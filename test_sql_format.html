SQL格式化功能测试

访问地址： http://localhost:9866/webdb

测试步骤：

  1. 访问主页面
  2. 切换到查询tab（可以是主查询或新建查询）
  3. 输入未格式化的SQL，例如：
    4. SELECT id,name,email FROM users WHERE status=1 AND deleted=0 ORDER BY created_at DESC
  4. 点击"编辑"菜单 → "SQL格式化"
  5. 检查SQL是否被正确格式化

修改内容总结：

修改1完成： 修改了editMenu.js文件，实现了SQL格式化功能
修改2完成： 添加了formatSql()函数，处理点击事件
修改3完成： 添加了formatSqlText()函数，实现SQL格式化逻辑
修改4完成： 支持主查询tab（ID: query）和新建查询tab（ID: query-1, query-2等）

SQL格式化功能特性：

  • 自动检测当前活动tab： 检查.tab-item.active
  • 支持两种查询tab： 主查询(#sqlInput)和新建查询(.sqlInput[data-tab])
  • 验证检查： 检查是否在查询tab中、SQL是否为空
  • 基本格式化规则：
    • 统一换行符
    • SQL关键字前添加换行
    • SELECT子句中的逗号后换行和缩进
    • 自动缩进处理
    • 清理多余空行
  • 错误处理： 友好的错误提示信息
  • 成功反馈： 显示"SQL格式化成功"消息

支持的SQL关键字：

SELECT, FROM, WHERE, JOIN, LEFT JOIN, RIGHT JOIN, INNER JOIN,
GROUP BY, ORDER BY, HAVING, UNION, UNION ALL, INSERT INTO,
UPDATE, DELETE FROM, CREATE TABLE, ALTER TABLE, DROP TABLE

格式化示例：

输入（未格式化）：

SELECT id,name,email FROM users WHERE status=1 AND deleted=0 ORDER BY created_at DESC

输出（格式化后）：

SELECT
    id,
    name,
    email
FROM users
WHERE status=1
    AND deleted=0
ORDER BY created_at DESC

代码结构：

文件： c:\work\webdb\src\main\resources\public\editMenu.js

主要函数：

  • formatSql() - 处理菜单点击，获取当前SQL并调用格式化
  • formatSqlText(sql) - 核心格式化逻辑

注意事项：

  • 需要确保用户已经切换到查询tab
  • SQL不能为空
  • 格式化功能是基本的，对于复杂的嵌套SQL可能有限
  • 使用layer显示提示消息，需要确保layer已加载

新增功能：两种格式化模式

新增功能： 现在提供两种SQL格式化模式

基本模式：

  • 快速格式化
  • 主要关键字前添加换行
  • SELECT子句逗号后换行
  • 基本缩进处理
  • 适合快速整理简单SQL

高级模式：

  • 完整格式化功能
  • 支持更多SQL关键字
  • 处理括号缩进
  • VALUES子句格式化
  • 复杂的缩进逻辑
  • 适合复杂的嵌套SQL
