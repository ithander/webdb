# Product Overview

**webdb** - A web-based database management tool that provides a unified interface for managing multiple database types (MySQL, MariaDB, H2, and Dameng).

## Purpose

webdb allows users to:
- Configure and manage multiple database connections
- Browse database schemas (tables, columns)
- Execute SQL queries and updates
- View query results with execution statistics

## Key Features

- Multi-database support with a consistent interface
- Session-based connection management
- H2 database for configuration storage (embedded or file-based)
- Web-based UI using Layui framework
- RESTful API for database operations

## Target Users

Database administrators and developers who need quick access to multiple databases through a single web interface.
