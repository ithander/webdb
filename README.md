# webdb

#### 介绍
用SpringBoot技术做数据库客户端

#### 软件架构
软件架构说明

#### 适用情况
用堡垒机的时候，不开放3306端口
只能用web技术+nginx技术

#### 安装教程

1.  直接下载jar包，运行就行（得到java运行环境,JDK17）
2.  你也可以下载源码，自己打包


#### 使用说明

1.  只有一个SpringBoot，有页面，但不是前端项目，不需要搞那么多环境依赖
2. 添加完数据库的连接信息，它们都会加密存到本地浏览器缓存，也就是说，换台电脑，别人打开页面是看不到你的连接信息的。
