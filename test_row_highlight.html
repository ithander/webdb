高亮样式示例：

这是高亮行的视觉样式：

  • 背景颜色：#e6f7ff (浅蓝色)
  • 边框颜色：rgba(64, 158, 255, 0.3) (半透明蓝色)
  • 阴影效果：0 0 5px rgba(64, 158, 255, 0.3)
  • 悬停效果：鼠标悬停时背景变为#d6e7ff (稍深的蓝色)

功能特性：

  • 整行高亮： 点击数据表中的任何单元格都会高亮整行
  • 单选模式： 一次只能选择一行，点击其他行时前一行高亮自动消失
  • 右键支持： 右键点击时也会高亮行并显示上下文菜单
  • 文本选择： 点击行时会自动选中整行文本（便于复制）
  • 视觉区分： 高亮行与其他行有明显视觉区别
  • 兼容编辑： 编辑状态的行有不同样式（黄色背景）

CSS样式代码：

/* 行高亮样式 */
.data-edit-table tbody tr.row-highlight {
    background-color: #e6f7ff !important;
    box-shadow: 0 0 5px rgba(64, 158, 255, 0.3);
    position: relative;
}
.data-edit-table tbody tr.row-highlight td {
    border-color: rgba(64, 158, 255, 0.3) !important;
}
.data-edit-table tbody tr.row-highlight:hover {
    background-color: #d6e7ff !important;
}
/* 编辑状态行样式 */
.data-edit-table tbody tr.editing {
    background-color: #fffbe6 !important;
}
/* 新增行样式 */
.data-edit-table tbody tr.new-row {
    background-color: #f0fff0 !important;
}

JavaScript代码修改：

左键点击事件（原代码）：

// 原代码：分别处理行号列和内容列
if (!$td.data('col')) { $row.addClass('row-highlight'); ... }
else { $td.addClass('cell-highlight'); ... }

左键点击事件（新代码）：

// 新代码：统一处理，点击任何单元格都高亮整行
$tbody.find('tr').removeClass('row-highlight');
$row.addClass('row-highlight');

右键点击事件（新代码）：

// 右键点击时也高亮行
var $td = $(this), $row = $td.closest('tr');
// 高亮选中的行
$tbody.find('tr').removeClass('row-highlight');
$row.addClass('row-highlight');

注意事项：

  • 行高亮功能只在数据tab页生效
  • 编辑状态的行（双击进入编辑）有不同样式（黄色背景）
  • 新增的行也有特殊样式（绿色背景）
  • 高亮行在翻页或刷新数据时会自动清除
  • 文本选择功能便于用户复制整行数据
